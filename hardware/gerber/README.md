# Gerber-Dateien (JLCPCB)

Hier liegen die Fertigungsdaten (Gerber) für die Bestellung bei
[JLCPCB](https://jlcpcb.com/) – je Platine als eigenes `.zip`.

Bitte Dateien nach folgendem Schema ablegen:

| Platine        | Dateiname (Vorschlag)        | Status               |
| -------------- | ---------------------------- | -------------------- |
| Deckel-Platine | `gerber-deckel.zip`          | *(noch hinzufügen)*  |
| Hauptplatine   | `gerber-haupt.zip`           | *(noch hinzufügen)*  |
| 3. Platine     | `gerber-platine3.zip`        | *(noch hinzufügen)*  |

> Zum Bestellen das jeweilige `.zip` bei JLCPCB hochladen. Ablauf siehe
> [`docs/fertigung.md`](../../docs/fertigung.md).

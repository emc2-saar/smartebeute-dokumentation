# Schaltpläne (Schematics)

Hier liegen die Schaltpläne der Platinen. Sie zeigen die Verschaltung der Bauteile und
helfen beim Bestücken und bei der Fehlersuche.

Bitte Dateien nach folgendem Schema ablegen (z. B. als PDF):

| Platine        | Dateiname (Vorschlag)        | Status               |
| -------------- | ---------------------------- | -------------------- |
| Deckel-Platine | `schaltplan-deckel.pdf`      | *(noch hinzufügen)*  |
| Hauptplatine   | `schaltplan-haupt.pdf`       | *(noch hinzufügen)*  |
| 3. Platine     | `schaltplan-platine3.pdf`    | *(noch hinzufügen)*  |

> Die Schaltpläne werden **noch hochgeladen**. Verweis in der Doku siehe
> [`docs/fertigung.md`](../../docs/fertigung.md).
